# Каталог башен

Веб-панель для типов оборонительных башен, вариант 23. Игра эту страницу не рисует: администратор правит список, а виджет и сайт читают его из браузера.

## Запуск

Из корня проекта, одной командой на все веб-лабы:

```bash
python -m http.server 8765
```

Страница: http://localhost:8765/05_каталог/

По `file://` модули не откроются.

## Поля записи

| Поле | Смысл | Ограничение |
| --- | --- | --- |
| name | Название типа | Обязательно, до 24 символов |
| damage | Урон выстрела | Число от 1 до 200 |
| radius | Радиус атаки, px | Число от 40 до 300 |
| energyType | Подпись типа энергии | Обязательно, до 16 символов |
| cost | Цена постройки | Число от 1 до 500 |

Идентификатор создаёт `crypto.randomUUID()`. В таблицу он не выводится.

Ключ хранилища: `defense_towers`. После каждого добавления, сохранения и удаления в него записывается весь JSON-массив. При первом открытии, если ключа ещё нет, кладутся лазер, пулемёт и мортира.

## Как проверить

1. Добавить тип с пустым именем — под полем появится текст ошибки, строка в таблицу не попадёт.
2. Сдвинуть ползунок радиуса — в таблице остаются только типы не больше выбранного значения.
3. Нажать «Править», изменить урон, «Сохранить». Обновить страницу: новое число на месте.
4. «Удалить» спрашивает подтверждение. После согласия строки нет и в Application → Local Storage.
5. В имени с символами `<` и `>` на странице виден текст, а не новая разметка. Перед вставкой строка проходит `escapeHtml`.
