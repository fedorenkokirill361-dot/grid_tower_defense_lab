# Кооперативная оборона: Башни и Энергия

Вариант 23. Монстры идут по тропе к базе. Башня стреляет только тогда, когда до неё доходит питание от генератора. Сначала это окно на Python, затем те же правила на JavaScript: расчёт, поле, каталог башен и сайт.

## Состав

| Папка | Лаба | Что внутри |
| --- | --- | --- |
| [`01_игра`](01_игра) | 1 и 2 | Окно Pygame: тропа, башни, энергосеть, JSON, имя игрока и таблица результатов |
| [`02_бот`](02_бот) | 3 | Телеграм-бот «Штаб обороны» |
| [`03_расчеты`](03_расчеты) | 4 | Расчёт волны и питания на JavaScript, без окна |
| [`04_виджет`](04_виджет) | 5 | Поле на Canvas |
| [`05_каталог`](05_каталог) | 6 | Таблица типов башен |
| [`06_сайт`](06_сайт) | 7 | Сайт: поле по центру, магазин башен справа |

В каждой папке свой `README.md`: как запустить эту часть и из чего она состоит.

## Запуск

### Игра

Двойной щелчок по `01_игра/ЗАПУСК.bat`.

Из папки `01_игра`:

```bash
pip install -r requirements.txt
python main.py
```

### Бот

Двойной щелчок по `02_бот/ЗАПУСК.bat`.

Токен читается из `02_бот/.env` и в репозиторий не входит. Образец полей — `02_бот/.env.example`.

### Сайт, виджет и каталог

Двойной щелчок по `06_сайт/ЗАПУСК_САЙТ.bat`. Окно не закрывать, затем открыть:

- http://localhost:8765/06_сайт/
- http://localhost:8765/04_виджет/
- http://localhost:8765/05_каталог/

Страницы нужно открывать по `http://`. Если открыть файл с диска, браузер не загрузит модули.

### Проверка расчётов

Из папки `03_расчеты`:

```bash
node selftest.js
```
