# Башни и энергия

Вариант 23, «Кооперативная оборона: Башни и Энергия». Монстры идут по тропе к базе. Башня стреляет, только если до неё доходит питание от генератора.

## Состав

| Папка | Лаба | Что внутри |
| --- | --- | --- |
| [`01_игра`](01_игра) | 1 и 2 | Окно Pygame: тропа, башни, энергосеть, JSON, имя игрока и таблица результатов |
| [`02_бот`](02_бот) | 3 | Телеграм-бот «Штаб обороны» |
| [`03_расчеты`](03_расчеты) | 4 | Расчёт волны и питания на JavaScript, без окна |
| [`04_виджет`](04_виджет) | 5 | Поле на Canvas |
| [`05_каталог`](05_каталог) | 6 | Таблица типов башен |

## Запуск

Игра: двойной щелчок по `01_игра/ЗАПУСК.bat`.

Бот: двойной щелчок по `02_бот/ЗАПУСК.bat`. Токен читается из `02_бот/.env` и в репозиторий не входит. Образец полей — `02_бот/.env.example`.

Проверка расчётов: из папки `03_расчеты` выполнить `node selftest.js`.

Страницы открываются по `http://`, не как файл с диска. Из корня проекта:

```bash
python -m http.server 8765
```


- http://localhost:8765/04_виджет/
- http://localhost:8765/05_каталог/
