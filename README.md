# Башни и энергия

Вариант 23, «Кооперативная оборона: Башни и Энергия». Монстры идут по тропе к базе. Башня стреляет, только если до неё доходит питание от генератора.

Первая и вторая лабораторные лежат в одной папке `01_игра`. Во второй добавлены имя игрока, таблица `scores.csv` и прежний разбор JSON с логом поражения. Как устроена партия — в `01_игра/README.md`.

## Запуск

Двойной щелчок по `01_игра/ЗАПУСК.bat`.

Из папки `01_игра`:

```bash
pip install -r requirements.txt
python main.py
```
