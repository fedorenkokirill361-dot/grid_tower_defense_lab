# Виджет обороны

Игровое поле варианта 23 на Canvas. Монстры, выстрелы и энергосеть считаются в `03_расчеты`. Эта страница их рисует.

## Запуск

Из корня проекта:

```bash
python -m http.server 8765
```

Открыть http://localhost:8765/04_виджет/

Адрес `file://` не подходит: браузер не загружает `import` между файлами.

## Управление

| Действие | Клавиша или мышь |
| --- | --- |
| Сдвинуть обзор | W A S D или стрелки |
| Поставить башню | Клик по свободной клетке |
| Новая партия | R или кнопка «Заново» |

Шаг симуляции фиксированный: 1000/60 мс. Кадры браузера копятся в накопителе и тратятся на эти шаги, поэтому скорость монстров не зависит от частоты экрана. Клавиши пишутся в объект флагов по `keydown`/`keyup`, а читаются в начале шага. Для WASD и стрелок вызывается `preventDefault`, чтобы страница не прокручивалась.

Обзор — жёлтая точка. Клетки дальше 280 px от неё не рисуются. Кнопка «Показать карту» на 5 секунд снимает ограничение.

## Что видно на поле

- Серые клетки и коричневая тропа.
- Жёлтый генератор.
- Тонкая синяя линия между запитанными башнями.
- Голубая башня с питанием, серая без питания.
- Жёлтая точка над башней, когда она целится или на кулдауне.
- Красный луч в момент выстрела. Прозрачность берётся из `beam.alpha` и падает до нуля.
- Монстр появляется из точки: радиус и прозрачность растут первые 220 мс.

Полоска здоровья базы меняет цвет: зелёный, жёлтый, красный. Текст пишется в уже существующие элементы, новые узлы каждый кадр не создаются.

## Сценарии

Реестр в `js/scenarios.js`. Кнопка с `data-scenario` вызывает функцию с тем же именем. Из консоли браузера доступен тот же реестр:

```js
DefenseHQ.scenarios.laserVolley()
DefenseHQ.scenarios.callWave()
```

| Имя | Что делает |
| --- | --- |
| pause | Останавливает и снова запускает расчёт |
| callWave | Обнуляет таймер до следующего монстра |
| laserVolley | Разрешает запитанным башням выстрелить, не дожидаясь секунды |
| powerSurge | На 4 секунды уменьшает затухание питания вдвое, цепочка достаёт дальше |
| revealMap | На 5 секунд показывает всё поле |
| grantGold | Добавляет 80 золота |

Тип башни по умолчанию — первая запись каталога `defense_towers`. Список меняется на странице `05_каталог`.
