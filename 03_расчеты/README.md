## Запуск

Нужен Node.js 18+. Команды из папки `03_расчеты`:

```bash
node selftest.js
```

47 проверок печатают `OK`. Код выхода 0. Если проверка не сошлась, строка начинается с `FAIL`, код выхода 1.

## Формулы

Питание на расстоянии d:

`P(d) = 1 * exp(-k * d)`

`k = ln(1 / 0.15) / 150`. Порог 0.15 приходится на 150 px — это дистанция D из первой лабы. Связь в графе есть, только если `P(d) > 0.15`. На ровно 150 px связи уже нет, как и в Python-версии.

Попадание башни с радиусом R:

`H(d) = 1 * exp(-kR * d)`, `kR = ln(1 / 0.15) / R`

Выстрел проходит, если `H(d)` не ниже 0.15. При обычном k это совпадает с кругом радиуса R. Если k удвоить, порог сдвигается на R/2: цель на краю старого круга уже не берётся.

В первой лабе проверялось только `d <= R` и `d < D`. Здесь сначала считается величина, и порог берётся из формулы, а не подбирается отдельно.

## Состояния

Монстр:

| Состояние | Когда |
| --- | --- |
| March | Идёт к следующей опорной точке |
| Stagger | Получил урон и стоит. Запоминает номер точки, к которой шёл |
| Return | Снова идёт к запомненной точке |
| March | Точка достигнута, маршрут продолжается |
| Dead | Здоровье дошло до нуля |
| Leaked | Дошёл до конца тропы |

Башня:

| Состояние | Когда |
| --- | --- |
| Unpowered | BFS от генератора до неё не дошёл |
| Idle | Питание есть, цели в пороге нет |
| Aim | Цель найдена, в этот шаг уходит урон |
| Cooldown | Секунда после выстрела. Потом снова Idle или Aim |

`Rect.move` возвращает новый прямоугольник. Командир обзора двигается через `slide`: упёршись в рамку поля по одной оси, по второй он всё ещё проходит.
